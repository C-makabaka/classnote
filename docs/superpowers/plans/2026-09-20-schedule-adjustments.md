# 课记 1.1 调课实现计划

用户已批准选择框及四类调整，直接执行。本计划兼作补充设计。

## 规则
- 单次移动、两课对调、停课日期范围及多组补课日期、从某周起长期变更一个时段。
- 基础课表 + 有序、可逆的日期实例补丁。实例键为课程 ID / 基础时段索引 / 原始日期。
- schemaVersion 1 增加可选 adjustments，不迁移或重置旧资料。每个补丁保存 before/after；载入及备份恢复校验完整重放。
- 补课选择准确来源日；单双周按来源日计算。可补已停课但尚未补过的日期。
- 冲突阻止保存，预览显示冲突课程、日期、节次。对调为原子操作。
- 长期变更保留起始周之前历史；已做单次调整或停课的实例保留例外。所有变更可在记录中按倒序撤销。
- 有调整时冻结基础时段和学期起点/周数，防止记录引用失效；课程名称、要求、笔记、作业仍可编辑。新课程可创建，需检查实际课表冲突。
- 周视图显示最终安排和灰色原位置；有周末课程时展开周末。全部周次仍是基础课表，注明需选择周次查看实际调整。
- 从实例进入笔记自动带实际日期和原始日期；任务、提醒、日历副本截止时间不变。

## Task 1: 日期调课领域
先写行为测试并观测失败，再实现 schedule.js、Core 接入及 Java 同等校验。覆盖四类、来源单双周、冲突原子性、跨周、撤销、旧数据、损坏补丁、冻结和不改作业。

## Task 2: 界面
选择框四种类型、相关字段、预览确认、记录撤销；首页入口、长按入口、详情入口、周末及灰色记录、笔记日期。先添加浏览器行为测试，观测失败后实现，运行原界面测试。

## Task 3: 发布验证
完整 Node + Java + Playwright，独立整体验证审查，修复重要发现。版本 1.1.0/code2，沿用已有签名。打包验证 APK、ZIP 源码及中文说明，保存并交付。

## Review Focus
异常调整导入重放、长期变更和临时例外先后顺序、补课重复映射、午夜日期及跨年、长按误点、旧备份恢复和 JS/Java 校验一致、归档课程恢复冲突。
