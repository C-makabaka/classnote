# 课记 Android 1.0 设计

用户已确认交互预览与日期，并于本轮明确要求开始开发。以下是该确认的实现记录，不增加再次批准流程。

## 目标与界面
- 个人离线记录课堂照片、课程规则和作业，期末能按课程和课次回看。
- 首页为截图的五列课表，14节；浅黄色背景、浅蓝课程、绿色侧边，制服课为黄色。
- 默认第一周周一为2026-09-07，17周；按设备当天日期计算当前周。支持上一周、下一周、周次选择、全部周次及回当周；显示周一起至周日止日期。
- 课程标题为接近黑色的粗体。同一课程所有课块共用未完成作业数；0不显示。
- 默认录入截图的7门课程、10个排课记录。周次单双规则保留。无虚构作业、笔记、成绩比例。
- 点击课程进入课堂笔记／作业／课程信息。制服说明只以详情小字呈现。
- 底部课表／作业／设置。课程管理可从设置与首页进入。

## 数据与操作
- 课程：名称、简称、教师、制服开关、课堂要求、成绩构成、其他备注、多个排课时段；创建与编辑、归档。课程归档不删除历史资料。
- 笔记：课程、课次、日期、主题、正文、重点开关、多张照片；新增、修改、删除、重点筛选、文字搜索。照片点击查看原图，可调整顺序；保留原始导入文件。
- 作业：课程、自动建议序号（允许修改）、标题、要求、截止时间（可空）、提交方式、备注、多张照片、提醒提前分钟数（可自定义）；新增、修改、完成／恢复、删除。
- 未完成优先按截止时间排序，未设截止最后；完成变灰、标题划线并沉底，保存完成时间。
- 记录写入应用私有文件，以原子替换提交。保存失败时不显示成功。图片复制进私有目录，原相册删除不会使笔记失效。
- 导出完整ZIP备份含JSON和媒体；恢复前确认替换，校验版本、引用与ZIP路径，先在临时目录完整校验再提交；失败保留旧数据。
- 数据模型含ownerId、spaceId、revision、updatedAt，记录标识使用UUID，删除使用墓碑；共享接口返回未启用，附未来服务端鉴权与冲突处理伪代码，不暴露空的共享按钮。

## 安卓系统能力
- Android 8.0（API26）及以上，targetSdk35。Java原生外壳＋打包在APK内的HTML/CSS/JS，不依赖网站、账号或网络。
- 原生相册文件选择和系统相机；仅授权指定媒体文件URI，不请求全部相册权限。
- AlarmManager定时提醒，通知权限按需申请；精确提醒未授权时使用系统允许的近似提醒并说明状态。编辑、完成、删除后重排/取消；重启、时间改变、应用升级后恢复；接收器触发前再读取作业状态。
- 日历采用ACTION_INSERT预填，用户在日历内保存。不声称已写入或可自动修改外部日历事件；编辑/完成应用作业不会同步改变已另存的日历事件。
- WebView仅加载app内部HTTPS虚拟源，关闭文件访问，不允许外部页面进入有原生桥接的WebView。应用不申请INTERNET权限。

## 验收与边界
- 自动化检验日期边界、单双周、徽标计数、作业排序与恢复、数据验证、持久化失败、ZIP遍历防护。
- 浏览器验收实际打包界面：320px及常用手机宽度、表单、持久化、照片、完成状态。
- APK必须完成资源编译、Java编译、DEX生成、对齐、签名验证。若无真实设备/模拟器，明确原生系统交互仍需真机测试。
- 第一版不包含OCR、AI总结、账号服务器或实际多人同步。
