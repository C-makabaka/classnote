# 历史更新

## 1.5.1

优化照片双击放大。

## 1.5.0 笔记文件附件

- 在“课堂笔记 → 记笔记 / 编辑笔记 → 文件附件”中点“添加文件”，可以多选 PDF、Word、PPT、音频和其他文件。
- 附件复制进应用私有目录，保留原文件名、大小和类型；外部原文件移动或删除不影响已保存副本。
- 笔记列表和编辑页均可点击附件，交给手机中对应的应用打开；没有阅读器时会提示。附件不会在 WebView 内执行。
- 每个文件最多64MiB（界面标作64MB），每条笔记最多100个附件。主题和正文都可留空，只添加文件也能保存。
- 附件随草稿保存，支持重新打开、导入结果重投去重、移除确认和文件名搜索。移除后需要保存笔记才生效。
- 完整 ZIP 备份包含附件原文件与元数据；仍可读取旧版本备份。含附件的新备份请用1.5.0或更高版本恢复。
- 包名与签名不变，versionName `1.5.0`，versionCode `12`。交付 APK 使用原签名，可覆盖升级。

## 1.4.5 放大后的边缘切图

- 修复放大后不能切换照片的配置遗漏，恢复PhotoSwipe的allowPanToNext。
- 放大图片内部拖动仍是平移；到达左/右边缘后松手，再向外滑可切到上一张/下一张，无需先缩小。
- 下一张自动适配屏幕；首尾不循环，短拖回弹；双指缩放后的剩余手指不触发意外切图。
- 无工具栏、即时空白/系统返回、防点击穿透及1.4.4的渐进原图加载继续保留。
- 包名与签名不变，versionName `1.4.5`，versionCode `11`，可直接覆盖安装。

## 1.4.4 图片预览响应优化

- 直接使用列表中已加载的缩略图建立预览，不再打开时同步读取整组原图尺寸。未知邻图单独加载，保持各自比例。
- 浏览和左右拖动用轻量图片，放大停下100ms后才异步加载原图；原图失败保留可查看的缩略图。大组图片只保留当前图的原图解码引用。
- 移除开关场动画等待，打开即接受手势；系统返回和点空白立即关闭。点击图片保留220ms双击识别窗口，双击与双指缩放继续有效。
- 起步拖动识别后保留第一段位移；左右连续滑动、弹簧回弹和缩放动画保留。
- 系统栏隐藏/恢复使用稳定边距，不再跟随可见性改变WebView尺寸。隐藏栏区域填黑，图片外仍由遮罩阻止误触。
- 图片URL带会话代际，恢复备份后更新，避免同名旧图缓存；应用仍完全离线。
- 包名 `cn.cbhcool.classnote`，versionName `1.4.4`，versionCode `10`，沿用原签名覆盖安装。
- PhotoSwipe小范围修改源码在 `vendor/photoswipe-5.4.4/src/`，重建方法见 `docs/THIRD_PARTY.md`；完整MIT许可证随APK和源码交付。

## 1.4.3 跟手图片浏览

- 接入PhotoSwipe 5.4.4（MIT），保留左右滑动、弹簧回弹、双击/双指缩放、平移、下滑退出和防点击穿透。
- 黑色预览仅显示图片，不显示工具栏、按钮、张数和操作提示；JS/CSS离线打包。

## 1.4.2 沉浸式看图

- 黑色全屏，仅显示照片，移除返回、放大、上一张/下一张、张数和操作提示。
- 单击图片或空白退出；双击在放大与适应屏幕间切换；双指缩放，放大后单指平移。
- 适应屏幕时左右滑动切图，下滑超过阈值退出；放大时滑动只平移图片。
- 安卓系统返回键关闭看图；进入时隐藏系统状态栏和导航栏，离开后恢复。
- 关闭动画期间保留遮罩和底层交互锁，并拦截延迟点击，防止误触原页面。
- 包名 `cn.cbhcool.classnote`，versionName `1.4.2`，versionCode `8`，签名证书与1.4.1一致。直接覆盖安装，无需卸载。
- 浏览器手势和回归测试、APK构建和签名检查已通过；尚未在安卓真机实测系统栏隐藏/恢复与覆盖安装。

## 1.4.1 修复

- 作业卡片正文可点击，增加“查看 / 编辑”入口；进入编辑页自动回到顶部，可修改、保存和删除。
- 删除作业、笔记和移除照片采用与应用一致的确认面板，可取消、点击遮罩或按返回键关闭。
- 照片浏览按当前记录分组，显示张数；支持左右滑动、上一张/下一张、双指缩放、双击缩放、放大后拖动、适应屏幕、点空白返回。
- 图片缩放限制在照片区域，应用其他界面不跟随缩放。
- 课堂主题可留空；照片、正文或主题至少有一项。无主题记录显示“课堂记录”，数据中保留空主题。
- 界面和安卓保存/备份校验使用相同的空白内容规则，包含中文全角空格。
- 包名 `cn.cbhcool.classnote`，versionName `1.4.1`，versionCode `7`；与1.4.0使用同一签名。安装前可先导出备份，然后直接覆盖安装。
